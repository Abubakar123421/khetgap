# Synthetic fixtures

Run `python scripts/generate_synthetic_data.py` to reproduce:

- `sugarcane_clean.png`: straight rows with known large internal gaps.
- `sugarcane_hard.png`: rotated rows with weeds and a simulated shadow.
- `negative_no_rows.png`: soil-like image with no vegetation structure.

These images validate software behavior only. They are not agronomic evidence.
